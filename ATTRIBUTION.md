# Attribution

Gridcraft Embed uses the open-source [Gridcraft](https://github.com/storytold/gridcraft) engine, maintained by the ArtCraft Team and Gridcraft contributors, under MIT OR Apache-2.0. Original contributor credits remain compiled into the engine. The pinned source commit and integration patch are documented in [UPSTREAM.md](UPSTREAM.md).

The upstream source and its [asset inventory](https://github.com/storytold/gridcraft/blob/main/ATTRIBUTION.md) are fetched during builds. Desktop icons, branding files and upstream README screenshots are not copied into this repository.

The npm package contains generated Rust dependency licenses and default-font notices under `dist/notices/`. These notices remain part of the distributed runtime even though generated files are ignored by Git.
