# Upstream provenance

Source: https://github.com/storytold/gridcraft

Pinned upstream release: [v0.6.1](https://github.com/storytold/gridcraft/releases/tag/v0.6.1).

Pinned commit: `fc45b7f6d8ab79ef20f74e3c8347a2fd731e6af5`.

Rust source is fetched at this exact commit into the ignored .work/upstream directory during builds. It is not copied into this repository.

This independently maintained, unofficial React embedding preserves upstream licenses and contributor credits. Integration changes are maintained in patches/embed.patch against fc45b7f6d8ab79ef20f74e3c8347a2fd731e6af5. They add the browser embedding API, cells-only mode, and dark grid rendering. Browser clocks are provided by upstream. Dependency license notices are generated during builds and included in the npm package.
